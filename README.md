# CÉRÉBRON Ω — FARM 51 — ARCHITECTON STRUCT Ω

Specialized structural-engineering farm.

Scope: finite-element preprocessing, structural analysis, stress, strain, displacement, modal/dynamic analysis, buckling, fatigue preparation, meshing and evidence-producing validation.

Rules:
- REALITY > COHERENCE
- EVIDENCE > CONFIDENCE
- CLAIM <= EVIDENCE
- SIMULATION != TEST
- COMPUTATION != PROOF
- A solver success is not engineering validation.
- Unsupported engines remain unavailable until actually installed and benchmarked.

Initial MVP is deterministic and dependency-light. External FEA engines are registered as candidates until verified in the execution environment.
